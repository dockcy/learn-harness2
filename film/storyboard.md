# 《换马具》· 寓言 · 分镜表（约 184 秒）

**这条片只讲一件事**：模型（马）不许换，Harness² 怎样只改它外面那层 harness（马具），在一个任务里越改越好，又借经验库让下一个任务改得更快。

**全片的形象（一个世界）**：雪岭驿站。驿丞老周、一匹不许换的官马、一副马具、两位匠人（铜匠 / 银匠）、一个隔帘挑包裹的人、一摞按山分本的日志。
**全片的尺子**：顶上那张「路书」纸条——每跑一趟就多一行蹄印；滑倒处画红 ×，只出现一回的小绊是灰点，过了终点是金色对勾。
**颜色**：金 = 有证据撑腰的改动、规则句；红 = 出错（滑倒、被摘掉）；灰 = 只出现一回的噪声；铜色 / 银蓝 = 两位匠人各自的改动。
**结尾回到开场**：同一段雪路、同一个冰坡，这回马稳稳过去。
